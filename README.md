# trade-area-mcp — 상권분석 MCP 서버

상권분석에 필요한 네 갈래 공공 데이터를 하나의 MCP 서버로 묶었습니다. 좌표계가 소스마다
달라 서버 내부에서 통일합니다.

| # | 소스 | 범위 | 무엇을 주는가 |
|---|---|---|---|
| ① | 소상공인시장진흥공단 상가(상권)정보 | 전국 | 점포 위치·상호·업종(대/중/소), WGS84 경위도 |
| ② | 행정안전부 지방행정 인허가 20종 | 전국 | 인허가일자·폐업일자·영업상태 → **개·폐업 시계열** |
| ③ | 국가데이터처 SGIS 통계지리정보 | 전국 | 배후 인구·가구·주택, 업종테마별 사업체·종사자 |
| ④ | 서울 열린데이터광장 상권분석서비스 | 서울 | **추정매출·유동인구** (요일·시간대·성별·연령대 분해) |

매출과 유동인구를 무료로 주는 곳은 사실상 서울시뿐이라, 전국 분석은 ①②③으로 하고 서울은
④를 덧붙이는 구조입니다.

## 도구

| 도구 | 하는 일 |
|---|---|
| `list_data_sources` | 다루는 소스·업종·서비스·테마 코드와 인증키 설정 상태 안내 |
| `convert_coords` | EPSG:5174 / 5181 / 5186 / 5179 ↔ WGS84 변환 |
| `resolve_region` | 지역명·주소 → 행정구역코드(adm_cd) + 경위도 |
| `stores_nearby` | 반경 내 점포 조회 (거리 계산·업종 집계 포함) |
| `store_industry_mix` | 반경·행정동 단위 업종 구성비 |
| `list_industry_codes` | 소상공인 업종 대/중/소분류 코드 |
| `search_permits` | 업종·지역·기간·영업상태로 인허가 업소 조회 |
| `permit_open_close_trend` | 연도별 신규 인허가·영업중·폐업 구성 |
| `region_demographics` | 배후 인구·가구·주택·인구밀도 |
| `region_business_stats` | 업종 테마별 사업체수·종사자수 |
| `seoul_trade_areas` | 서울 상권 검색 → 상권코드 |
| `seoul_trade_area_stats` | 서울 상권 추정매출·유동인구·상주/직장인구·점포·집객시설 |
| `trade_area_report` | 좌표 하나로 상권 종합 프로파일 |

## 환경변수

| 변수 | 용도 |
|---|---|
| `DATA_PORTAL_KEY` | 공공데이터포털 서비스키 (①② 공용) |
| `SGIS_SERVICE_ID` | SGIS 서비스 ID |
| `SGIS_SECURITY_KEY` | SGIS 보안 Key |
| `SEOUL_OPENAPI_KEY` | 서울 열린데이터광장 인증키 |
| `MCP_GATE_KEYS` | 접근 게이트 허용 키 목록(쉼표 구분) |
| `MCP_GATE_MODE` | `enforce` 또는 `observe` |

## 실측으로 확인한 제약 (2026-09-04)

이 서버를 만들며 실제 호출로 확인한 것들입니다. 문서만 보고는 알 수 없어 조용히 틀리기
쉬운 항목이라 코드에도 상수로 박아 두었습니다.

- **인허가 지역 필터는 반드시 지번주소(`region`)로 걸어야 합니다.** 도로명주소는 2011년
  도입이라 그 이전에 폐업한 업소에는 값이 아예 없어, 도로명으로 좁히면 폐업 이력이 조용히
  절반 넘게 사라집니다. 영등포구 일반음식점 실측:

  | 구분 | 지번주소 LIKE | 자치단체코드 EQ | 도로명주소 LIKE |
  |---|---:|---:|---:|
  | 전체 | 28,287 | 28,301 | 15,738 |
  | 영업중 | 6,772 | 6,774 | 6,717 |
  | 폐업 | 21,515 | 21,527 | 9,021 |

  영업중만 보면 차이가 거의 없어 더 위험합니다 — 개·폐업 추이·생존율에서만 결과가 크게
  틀어집니다(폐업률 76% → 57%로 과소집계). 도구의 지역 인자는 `region`(지번주소)이 기본이고,
  `addrLike`(도로명)를 쓰면 응답에 경고가 붙습니다. 가장 정확한 것은 `orgCode`입니다.
- **인허가 API의 `numOfRows` 상한은 100이고, 넘겨도 에러 없이 잘립니다.** 1000을 요청하면
  100건만 오고 응답의 `numOfRows` 자체가 100으로 바뀝니다.
- **인허가 API에는 문서 표면에 드러나지 않는 `cond[필드::연산자]` 필터가 있습니다.**
  `cond[ROAD_NM_ADDR::LIKE]`, `cond[OPN_ATMY_GRP_CD::EQ]`, `cond[SALS_STTS_CD::EQ]`,
  `cond[LCPMT_YMD::GTE|LT]`, `cond[DAT_UPDT_PNT::GTE|LT]`, `cond[BPLC_NM::LIKE]`.
  이게 없으면 전국 전수(일반음식점만 229만 건)를 페이징해야 합니다.
- **SGIS 호스트는 `sgisapi.mods.go.kr` 입니다.** 구 주소 `sgisapi.kostat.go.kr` 은 빈 응답을
  돌려줍니다. 통계청이 국가데이터처로 개편되며 도메인이 바뀌었습니다.
- **SGIS 좌표변환 API는 EPSG:5174를 지원하지 않습니다.** `src=5174` 를 주면
  `errCd -200 "정의된 EPSG 코드값이 아닙니다"`. 그래서 proj4 로컬 변환을 씁니다.
  `+towgs84=-115.80,474.99,674.11,1.16,-2.31,-1.63,6.43` 로 변환한 결과를 같은 건물의
  소상공인 상가정보 WGS84 좌표와 대조해 **오차 9m** 를 확인했습니다.
- **서울 열린데이터광장은 1회 1,000행 상한**입니다. 1,001을 요청하면 `ERROR-336`.
  최신 기준년분기는 `20254`(2025년 4분기)이고, 2021년 이후 자료만 제공됩니다(2026-07-03 축소).
- **소상공인 상가정보는 1회 1,000건까지** 정상 반환됩니다.
